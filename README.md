Entry for the make.fun bounty [One Line, One Laugh](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3): a program that writes a single hilarious line of at most 200 characters to `/output/entry.txt`.

The line (v1):

> I asked the mirror for the truth. It showed me my search history.

Run it with `python3 main.py`. It writes exactly 65 characters, no trailing newline.
